# Assembleia — Elevato Bonsucesso

Resumo da assembleia registrada em 12/11/2026, com decisões, gestão eleita, orçamento e orientações aos moradores.

- `assets/prints/`: oito recortes das gravações, com votações, orçamento, cotas, vencimentos e entrega das chaves.
- `index.html`: página com imagem ilustrativa incorporada e layout responsivo.
- `transcricao_video_1.txt`: transcrição automática da primeira gravação.
- `transcricao_video_2.txt`: transcrição automática da segunda gravação.

As transcrições podem conter falhas de reconhecimento. Os principais nomes, valores e datas do resumo foram conferidos nas telas da assembleia. Há um intervalo de aproximadamente 3min35s entre as gravações.

Somente as duas versões de vídeo com tarjas são publicadas em `assets/videos/`, acompanhadas de legendas automáticas. Os arquivos originais, sem tarjas, não fazem parte deste repositório. As câmeras e identificações visuais são ocultadas; o áudio original é mantido. A imagem de referência foi extraída da apresentação exibida na assembleia.

## Publicação

GitHub Pages, a partir da raiz da branch `main`. Não é necessário instalar dependências nem compilar o site.
